## Notes for updating maps

After a map got changed by patches/updates, you can visit the affected location in the game and use /savemap to save the full size image.

Now you can update the map in this wikia by using the given update link.

This link should take you to a web page where you only have to select your local image, click _Upload_ and then _Ignore warning and save file anyway_.

**Thumbnails**

The location maps have about 17.7M pixel, but for automated thumbnail generation only 12.5M pixel are allowed. So without loss of quality the automated thumbnails can not be used.

If you feel like it, you are welcome to also update thumbnails affected by game patches/updates.

For this purpose use the already locally saved image. To reduce the size you can use online tools like [iloveimg](http://www.iloveimg.com/resize-image). You can reduce the size to much less than 1000px in height.

After generating the thumbnail you can upload it to the wikia using to link provided in to location table.
