There are a number of features and events in the game that give special rewards like [coins](https://rpg-mo.fandom.com/wiki/Coin), [MOS](/mos) and [experience](/experience):

*   [Captcha](/captcha) - Experience only
*   [Quests](/quests) - (Kill Quests)
*   [Party Quests](/party-quests)
*   [Skill Quests](/skill-quests)
*   [Trivia](/trivia)
*   [Arena](/arena)
*   [Daily Rewards](/daily-rewards)

Experience is distributed in some combat skills according to your current [Fighting mode](/fighting-mode).

Fighting mode (controlled): 2/3 Accuracy, 2/3 Strength, 2/3 Defense, 1 Health

Fighting mode (accurate): 2 Accuracy, 1 Health

Fighting mode (aggressive): 2 Strength, 1 Health

Fighting mode (defensive): 2 Defense, 1 Health

Fighting mode (cordial): 2 Health
