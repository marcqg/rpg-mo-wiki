## Basic

Materials are used for [Crafting Skills](/skills).

## Types

There are different type of materials.

| Type of material | Skill for |
| --- | --- |
| [Ores](/ores) | [Forging](/forging) |
| [Bars](https://rpg-mo.fandom.com/wiki/Bars)/[Moulds](https://rpg-mo.fandom.com/wiki/Bars) | [Carpentry](/carpentry), [Forging](/forging), [Jewelry](/jewelry) |
| Uncut gems | [Jewelry](/jewelry) |
| Gems | [Jewelry](/jewelry), [Forging](/forging), [Fletching](/fletching) |
| Seeds | [Farming](/farming) |
| Raw fish | [Cooking](/cooking) |
