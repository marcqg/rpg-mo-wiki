Enabling the Chat Extensions mod adds the chat filter and many other useful commands.

_The following commands are available via the /help in game._

| Command | Explanation |
| --- | --- |
| /afk | Use /afk or /afk (message) to set an automatic reply to people who whisper you if you are away from the keyboard. While your status is "AFK", if you type /afk again automatic replies will be disabled. Unless you are completely idling or are playing on a mobile device, you can still get captchas. |
| /combats | Use /combats to see everyone's [Combat Level](/combat-level) in your world. Use this to see your own [Combat Level](/combat-level) if you have NOT loaded /mods. |
| /cathedral | Use /cathedral to see how much time is left before you can start another [cathedral](/cathedral) run. Use /cooldowns for cathedral and towers in one list. |
| /cl | Use /cl with /mods enabled to see your [Combat Level](/combat-level). |
| /cooldowns | Use /cooldowns for a list of time left before you can start all Towers and Cathedral in a single command. |
| /counter | Use /counter to see the number of actions associated with a skill taken, damage dealt, number of kills, etc. This is tracked only for the current device, and can be cleared with /counter clear. |
| /daily | Use /daily to see the number of consecutive days you have on your [daily rewards](/daily-rewards) counter. |
| /find | Use /find (monster) or (material) or (town/land name) to get the map name or coordinates of what you\`re looking for. |
| /fire | Use /fire to see how much time is left before you can start another [Fire Tower](/fire-tower) run. Use /cooldowns for cathedral and towers in one list. |
| /friend | Use /friend (player) to quickly add or remove a player to/from your friends list. Example: /friend dendrek |
| /help | Use /help to see a list of the mod chat commands. To read a description of a command, type /help &#123;command}.<br/>List of commands: afk, combats, [cathedral](/cathedral), daily, find, friend, help, id, ignore, join, leave, maintenance, m00, mods, obj, online, o, penalty, ping, played, r, savemap, saveplayer, world, timer, totalexp, totalvalue, xp, wiki. |
| /ice | Use /ice to see how much time is left before you can start another [Ice Tower](/ice-tower) run. Use /cooldowns for cathedral and towers in one list. |
| /id | (For Debugging) Use /id (object) (params=) (value) to lookup information in the game\`s database. This command is mostly for debugging purposes and will not be useful to most players. |
| /ignore | Use /ignore (player) to quickly add or remove a player to/from your ignore list. Example: /ignore dumbplayer |
| /join | Use /join (CH) (where CH is a valid channel name, written with capital letters, such a EN, DE, 18, etc) to join that channel. Example: /join EN<br/>/join is also used to join any ongoing events, such as a trivia or arena tournament. (Must be In a town and right world to join a minigame) |
| /leave | Use /leave (CH) (where CH is a valid channel name, written with capital letters, such as EN, DE, 18, etc) to leave that channel. Example: /leave EN |
| /maintenance | Use /maintenance to see how much time is left until the next maintenance restart for the world you are on. |
| /maintenance all | Use /maintenance all to see how much time is left until the next maintenance restart for all worlds at once. |
| /market | Use /market to see your previous market transactions (buying and selling) for up to the previous 1 week (regular users) or 6 months (premium). |
| /m00 | Use /m00 to change your visual appearance into that of a.... cow! You can extend the duration of this command with /m00 # (such as /m00 30 to set the duration to 30 seconds). Maximum time is 120 seconds. Typing /m00 with no number resets timer to 1 second. |
| /mods | Use /mods to bring up the Enable [Mods](/mods) menu. |
| /nature | Use /nature to see how much time is left before you can start another [Nature Tower](/nature-tower) run. Use /cooldowns for cathedral and towers in one list. |
| /obj | (For Debugging) Use /obj (object) (id) (params) to list the params of the object(id). This command is mostly for debugging purposes and may not be useful to most players. |
| /online | Use /online to see a list of players who are currently online game wide. |
| /o | Use /o (player) to check if that player is online. It\`s a fast way to confirm a players online-status without scanning the /online list. Example: /o dendrek |
| /penalty | Use /penalty to see how many captcha points you have stored. You can save up to 4 points and must use the 5th. It is recommended that you use saved points when the 2x experience event is active. If you reach -5 points you\`ll go to jail. |
| /ping | Use /ping to see how much of a delay (called latency) there is between your computer and server. Every 1000ms equals a 1 second delay. |
| /ping all | Use /pingall to see how much of a delay (called latency) there is between your computer and servers for all worlds. |
| /played | Use /played to see how long it has been since you created your current character. This is a measure of time since you started, not of actual time played. Also, RPG MO uses a 20 hour day. |
| /r | Use /r to reply to the last person who whispered you. If a player has whispered you recently enough, /r will immediately change to /w "playername". Additionally, use PageUp and PageDown to cycle through previous whisper targets. |
| /savemap | Use /savemap to save current map into a .PNG file to your clipboard. Caution, might take a while to generate! Not to be used with a mobile device.<br/>_/savemap Dorpat_ |
| /savemonster | Use /savemonster then the monsters name, will save a PNG of the monster to your clipboard. Not to be used with a mobile device.<br/>_/savemonster Efreet_ |
| /savenpc | Use /savenpc then the npc name, will save a PNG of the npc to your clipboard. which includes mobs. |
| /saveplayer | Use /saveplayer then the players name, will save a PNG of the player to your clipboard.<br/>_/saveplayer Bbrian_ |
| /saveitem | Use /saveitem "item name" to save a .png file of an in-game item. Useful for images of items to upload to the online Wikia. |
| /saveobj | Use /saveobj for items like (town) chest, tavern or iron/iron ore/iron vein. In-game graphics that are not other /save item types. |
| /savepet | Use /savepet "pet name" to save a .png file of a pet. |
| /saveachievement | Use /saveachievement "achievement name" to save a .png files of an achievement. |
| /tax | Use /tax to see your current tax percent. Use /tax \[price\] to see your calculated prices. Premium players receive a discount to their market tax rate of 0.1% per month of continuous premium down from 4% to 3% |
| [/timer](/timer) | Use /timer to check already created timers. You can also create a countdown (using /timer set), a clock (using /timer start), remove timers (using /timer clear), and even give timers names (using /timer (name) (command)). Type /help timer (set/start/clear/name) for more details. |
| /tip | Use /tip to receive a random [game tip](/game-tips). |
| /totalexp | The /totalexp command will show your total accumulated experience in all skills.<br/>With /totalexp \[#\] you can see the total experience needed to reach a certain level.<br/>/totalexp \[#\] \[#\] will show you the total experience needed to advance from a certain level to an other one (for example /totalexp 10 16 will show you how much experience is needed to go from level 10 to level 16 in any skill) Experience needed for all skill levels is the same. |
| /xp | Use /xp to see if a 2x experience event is currently running and to see the duration if one is. |
| /wiki | Use /wiki to open up the in-game wiki. You can also perform a search using this command.<br/>/wiki (option1) (option2) (option3) etc, where each option "fills" in one of the search boxes in the wiki.<br/>For more details, type /help wiki options. The wiki has dropdown boxes that must be filled in.<br/>To do a wiki search using the /wiki command, you must "fill in" each box with an appropriate value. The different parts of the search must be included for it to work.<br/>Related: See the [Wiki Chat Commands Guide](/wiki-chat-commands-guide) for an in-depth guide of wiki commands. |
| /world | Use /world to see which world you are in currently.<br/>Use /world 1 to connect to world 1.<br/>Use /world 6 to connect to world 6.<br/>etc.. |
