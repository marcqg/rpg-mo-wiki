The Multi-tool is a unique item in RPG-MO. It serves as many different tools which saves on space and has a wiki value of 3,600,000 coins which should be high enough to be a 'saved' item if you should [die](/death) while carrying it. Purchase one from the [MOS Market](/mos-market) for 900 MOS or from the [Player Market](/market-guide). The Multi-tool is:

*   45 unit [watering can](/farming) (must be unequipped when filling empty water vials)
*   [Steel Pickaxe](/steel-pickaxe) for use on any ore or vein
*   [Spade](/spade) for sand, Bones and Drowned Beast locations
*   [Steel Woodcutter's Axe](https://rpg-mo.fandom.com/wiki/Steel_Woodcutter%27s_Axe) for all trees
*   [Rake](/rake) for [farming](/farming)
*   [Forging Hammer](/forging-hammer) for [Anvil](/anvil) access
*   ALL Fishing tools - you only need the proper level to use - Using a fishing potion could let you fish at locations above your normal ability to use the regular tool.
*   [Lock Pick](/lock-pick) for Kill [Party Quest](/quests) food chests
