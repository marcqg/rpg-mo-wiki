> 🇫🇷 Traduction française — nom original (anglais) : **Silk Fabric** — <a href="/rpg-mo-wiki/silk-fabric">voir la page en anglais</a>

Le Silk Fabric est un matériau utilisé pour fabriquer l'Armure Magique, les Sorts et les Arcs d'Archerie. Le [Bag of Worms](https://rpg-mo.fandom.com/wiki/Bag_Of_Worms), qui fait pousser du Silk Fabric, peut être acheté auprès du [Wandering Farmer](/wandering-farmer) pour 5520 pièces.
