> 🇫🇷 Traduction française — nom original (anglais) : **Best Present** — <a href="/rpg-mo-wiki/best-present">voir la page en anglais</a>

Disponible au [MOS Market](https://rpg-mo.fandom.com/wiki/Mos_Market) pour 350 MOS ou via tes récompenses de hauts faits (Achievement Rewards) pour 100 points, cet objet [![Best Present](https://static.wikia.nocookie.net/rpg-mo/images/3/34/Best_Present.png/revision/latest?cb=20150225233728)](https://static.wikia.nocookie.net/rpg-mo/images/3/34/Best_Present.png/revision/latest?cb=20150225233728) contient un objet aléatoire d'une valeur pouvant aller jusqu'à 450 000 pièces. Équipe-le dans ton [Inventaire](/inventory) pour recevoir ton cadeau.

Quatre [![Great Present](https://static.wikia.nocookie.net/rpg-mo/images/6/62/Great_Present.png/revision/latest?cb=20150225233729)](http://rpg-mo.wikia.com/wiki/File:Great_Present.png) [Great Presents](/great-present) peuvent être combinés à l'[Enclume](/anvil) pour fabriquer un [![Best Present](https://static.wikia.nocookie.net/rpg-mo/images/3/34/Best_Present.png/revision/latest?cb=20150225233728)](http://rpg-mo.wikia.com/wiki/File:Best_Present.png) Best Present.
