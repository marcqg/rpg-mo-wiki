> 🇫🇷 Traduction française — nom original (anglais) : **Oak Tree** — <a href="/rpg-mo-wiki/oak-tree">voir la page en anglais</a>

Le Oak Tree peut être coupé à partir du niveau 10 en [Woodcutting](/woodcutting). Une fois coupé avec succès, un Oak Log est obtenu. La valeur du rondin de chêne est de 60 pièces. Ce rondin peut être utilisé dans des compétences comme la [Carpentry](/carpentry), la [Forging](/forging) et la [Fletching](/fletching).

## Décoration d'île

Un Oak Tree peut aussi être acheté comme décoration pour ton île, mais il ne peut pas y être utilisé pour obtenir des rondins.

Aie le Oak Tree dans ton coffre et utilise le menu Build - Objects pour le placer. Fais pivoter l'arbre lors du placement pour changer son apparence et sa taille.

[Dorpat Decorations Shopkeeper](/dorpat-decorations-shopkeeper) - 35 000 pièces.
