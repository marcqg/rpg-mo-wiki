> 🇫🇷 Traduction française — nom original (anglais) : **Cactus** — <a href="/rpg-mo-wiki/cactus">voir la page en anglais</a>

Le Cactus peut être coupé à partir du niveau 5 en [Woodcutting](/woodcutting). Une fois coupé avec succès, du bois de cactus est obtenu. La valeur du bois de cactus est de 30 pièces. Ce bois peut être utilisé dans les compétences [Carpentry](/carpentry) et [Fletching](/fletching).

## Décoration d'île

Un cactus peut aussi être acheté comme décoration pour ton [Island](/island-deed), mais il ne peut pas y être utilisé pour obtenir du bois.

Aie le Cactus dans ton coffre et utilise le menu Build - Objects pour le placer. Fais pivoter le cactus lors du placement pour changer son apparence et sa taille.

[Dorpat Decorations Shopkeeper](/dorpat-decorations-shopkeeper) - 25 000 pièces.
