> 🇫🇷 Traduction française — nom original (anglais) : **Fir Tree** — <a href="/rpg-mo-wiki/fir-tree">voir la page en anglais</a>

Le Fir Tree peut être coupé dès le niveau 1 de Woodcutting. Une fois coupé avec succès, un Fir Log est obtenu. La valeur du rondin de sapin est de 10 pièces. Ce rondin peut être utilisé dans des compétences telles que la [Carpentry](/carpentry), la [Forging](/forging) et la [Fletching](/fletching).

## Décoration d'île

Un Fir Tree peut aussi être acheté comme décoration pour ton île, mais il ne peut pas y être utilisé pour obtenir des rondins.

Aie le Fir Tree dans ton coffre et utilise le menu Build - Objects pour le placer. Fais pivoter l'arbre lors du placement pour changer son apparence et sa taille.

[Dorpat Decorations Shopkeeper](/dorpat-decorations-shopkeeper) - 15 000 pièces.
