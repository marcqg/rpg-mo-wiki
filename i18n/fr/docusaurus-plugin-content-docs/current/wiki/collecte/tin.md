Le **Tin Ore** est un minerai récolté à partir d'une veine d'étain, ou peut être acheté auprès du [Dorpat Blacksmith](/dorpat-blacksmith). Il est utilisé avec le [copper ore](/copper) pour créer des [bronze bar](/bronze-bar).

## Peut être obtenu via

*   Tin Vein
*   [Dorpat Blacksmith](/dorpat-blacksmith)
*   [Bronze Golem](/bronze-golem)
