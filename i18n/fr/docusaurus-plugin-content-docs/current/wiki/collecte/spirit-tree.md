> 🇫🇷 Traduction française — nom original (anglais) : **Spirit Tree** — <a href="/rpg-mo-wiki/spirit-tree">voir la page en anglais</a>

Le Spirit Tree peut être coupé à partir du niveau 45 en [Woodcutting](/woodcutting). Une fois coupé avec succès, un Spirit Log est obtenu. Le Spirit Log est évalué à 260 pièces. Ce rondin peut être utilisé dans diverses compétences comme la carpentry et la forging.
