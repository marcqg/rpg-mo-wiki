> 🇫🇷 Traduction française — nom original (anglais) : **Hydra** — <a href="/rpg-mo-wiki/hydra">voir la page en anglais</a>

L'Hydra est un monstre PNJ agressif de NC 62 situé dans le [Dungeon I](https://rpg-mo.fandom.com/wiki/Dungeon).  
  
  

## Emplacements

| Emplacement | Quantité | Coordonnées |
| --- | --- | --- |
| [Dungeon I](https://rpg-mo.fandom.com/wiki/Dungeon) | 8 | (80, 11) |
| [Dungeon I](https://rpg-mo.fandom.com/wiki/Dungeon) | 5 | (47, 24) |

Pour entrer dans cette section du Dungeon, trouve l'échelle (Point D, sur la carte du monde) qui se trouve au sud-ouest de l'Avant-poste de Dorpat. L'Avant-poste de Dorpat se trouve dans la région sud-est de [Dorpat](/dorpat).
