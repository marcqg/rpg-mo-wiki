Boss Retaliation est un événement chronométré créé automatiquement trois fois par jour, mais qui peut aussi être déclenché par un joueur à l'aide de DEUX (2) Minigame Scrolls disponibles au [MOS Market](/mos-market) ou vendus dans le [Player Market](/market-guide) via votre coffre.

Les horaires de l'événement sont 23h - 15h - 7h avant la prochaine **/maintenance** sur le Monde 6.

Après l'annonce dans le chat, vous avez 5 minutes pour basculer sur le bon monde et taper **/join** dans le chat pour être téléporté vers l'événement. Cet événement dure 10 minutes ou moins si toutes les parties du boss sont tuées. Le blocage multi-combat est désactivé pendant ces événements. Pour attaquer au corps à corps/à la magie, vous devez avoir accès à l'une des cases adjacentes de chaque partie. De nombreux archers peuvent attaquer à distance.

**VOS OBJETS NE SONT PAS PROTÉGÉS SI VOUS MOUREZ EN PARTICIPANT À CES ÉVÉNEMENTS ! Les règles normales de perte d'objets s'appliquent : les 2 objets de plus grande valeur /wiki et le familier équipé, OU les 7 objets de plus grande valeur /wiki et le familier équipé sont protégés si une [Potion de Préservation](https://rpg-mo.fandom.com/wiki/Potion_of_Preservation) est équipée.**

Le butin obtenu est constitué de clés Boss Retaliation Rare [![Retaliation Key -Rare-](https://static.wikia.nocookie.net/rpg-mo/images/6/62/Retaliation_Key_-Rare-.png/revision/latest?cb=20181030121602)](https://rpg-mo.fandom.com/wiki/Retaliation_Key_-Rare-), Legendary [![Retaliation Key -Legendary-](https://static.wikia.nocookie.net/rpg-mo/images/5/57/Retaliation_Key_-Legendary-.png/revision/latest?cb=20181030121632)](https://rpg-mo.fandom.com/wiki/Retaliation_Key_-Legendary-) ou Common [![Retaliation Key -Common-](https://static.wikia.nocookie.net/rpg-mo/images/4/41/Retaliation_Key_-Common-.png/revision/latest?cb=20181030121656)](https://rpg-mo.fandom.com/wiki/Retaliation_Key_-Common-). Si vous obtenez un butin, ce sera au moins une clé Common, mais il est possible de ne rien obtenir du tout. Utilisez les clés à la [Taverne](/tavern) sur les coffres Retaliation qui s'y trouvent.
