> 🇫🇷 Traduction française — nom original (anglais) : **Banana Tree Seed** — <a href="/rpg-mo-wiki/banana-tree-seed">voir la page en anglais</a>

**Banana Tree Seed** est une graine que l'on peut planter dans une [Terre](/soil) ratissée sur une [Île du Joueur](/player-island) avec le niveau 28 en [Agriculture](/farming), et qui produit une [Banana](/banana) après 13 minutes. Récolter le fruit rapporte 32 points d'expérience en Agriculture.
