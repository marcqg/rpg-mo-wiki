La Furnace est utilisée pour les compétences [Forging](/forging), [Alchemy](/alchemy) et [Jewelry](/jewelry). Aucun outil n'est nécessaire pour utiliser la furnace, il suffit d'équiper les matériaux pour compléter la recette.
