> 🇫🇷 Traduction française — nom original (anglais) : **Veles Cape** — <a href="/rpg-mo-wiki/veles-cape">voir la page en anglais</a>

**Veles Cape** est une cape de [Magie](/magic) de niveau 20. Elle peut être obtenue en tant que butin de divers monstres.

Une Veles Cape peut être enchantée pour devenir une Enchanted Veles Cape.
