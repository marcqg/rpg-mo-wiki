> 🇫🇷 Traduction française — nom original (anglais) : **Spirit Wings** — <a href="/rpg-mo-wiki/spirit-wings">voir la page en anglais</a>

Les **Spirit Wings** sont des [ailes](/wings) de niveau 50 en [Force](/strength). Elles ne peuvent être obtenues que via les [Great Presents](/great-present).

Les Spirit Wings peuvent être enchantées en Enchanted Spirit Wings.
