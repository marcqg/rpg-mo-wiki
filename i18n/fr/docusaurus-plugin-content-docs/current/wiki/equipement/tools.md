> 🇫🇷 Traduction française — nom original (anglais) : **Tools** — <a href="/rpg-mo-wiki/tools">voir la page en anglais</a>

Les outils sont des objets requis, utilisés dans les [Compétences](/skills) de récolte et d'artisanat pour effectuer certaines actions.

## [Minage (Mining)](/mining)

*   [![Spade](https://static.wikia.nocookie.net/rpg-mo/images/8/8e/Spade.png/revision/latest?cb=20150225215150)](/spade) **:** [Spade](/spade) sert à creuser le Sand.
*   [![Iron Pickaxe](https://static.wikia.nocookie.net/rpg-mo/images/a/a2/Iron_Pickaxe.png/revision/latest?cb=20150224203458)](/iron-pickaxe) **:** [Iron Pickaxe](/iron-pickaxe) est nécessaire pour miner les minerais.
*   [![Steel Pickaxe](https://static.wikia.nocookie.net/rpg-mo/images/d/d1/Steel_Pickaxe.png/revision/latest?cb=20150225231857)](/steel-pickaxe) **:** [Steel Pickaxe](/steel-pickaxe) est nécessaire pour miner les veines de minerai.
*   [![Mining Guild Permission](https://static.wikia.nocookie.net/rpg-mo/images/4/48/Mining_Guild_Permission.png/revision/latest?cb=20150225232633)](/mining-guild-permission) **:** [Mining Guild Permission](/mining-guild-permission) doit être équipé pour entrer dans la [Guilde des Mineurs](/mining-guild).

## [Bûcheronnage (Woodcutting)](/woodcutting)

*   [![Woodcutter's Axe](https://static.wikia.nocookie.net/rpg-mo/images/d/db/Woodcutter%27s_Axe.png/revision/latest?cb=20150224203421)](https://rpg-mo.fandom.com/wiki/Woodcutter%27s_Axe) **:** [Woodcutter's Axe](https://rpg-mo.fandom.com/wiki/Woodcutter%27s_Axe) sert à couper les arbres suivants :
    *   [Fir Tree](/fir-tree) (Niv1)
    *   [Cactus](/cactus) (Niv5)
    *   [Oak Tree](/oak-tree) (Niv10)
    *   [Willow Tree](/willow-tree) (Niv20)
    *   [Maple Tree](/maple-tree) (Niv35)
*   [![Steel Woodcutter's Axe](https://static.wikia.nocookie.net/rpg-mo/images/a/a1/Steel_Woodcutter%27s_Axe.png/revision/latest?cb=20150225010636)](https://rpg-mo.fandom.com/wiki/Steel_Woodcutter%27s_Axe) **:** [Steel Woodcutter's Axe](https://rpg-mo.fandom.com/wiki/Steel_Woodcutter%27s_Axe) sert à couper les arbres suivants :
    *   [Spirit Tree](/spirit-tree) (Niv45)
    *   [Blue Palm](/blue-palm) (Niv55)
    *   [Magic Oak Tree](/magic-oak-tree) (Niv65)
    *   [Void Tree](/void-tree) (Niv85)
    *   [Dragon's Blood Tree](https://rpg-mo.fandom.com/wiki/Dragon%27s_Blood_Tree) (Niv105)
    *   Elle peut aussi couper les arbres de niveau inférieur.
*   [![Woodcutting Guild Permission](https://static.wikia.nocookie.net/rpg-mo/images/e/e3/Woodcutting_Guild_Permission.png/revision/latest?cb=20170826090740)](/woodcutting-guild-permission) **:** [Woodcutting Guild Permission](/woodcutting-guild-permission) doit être équipé pour entrer dans la [Guilde des Bûcherons](/woodcutting-guild).

## Autre

Certains outils ne sont pas liés à une compétence spécifique mais servent à d'autres actions qui ne peuvent pas être réalisées sans eux.
