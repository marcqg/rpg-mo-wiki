**Raw Salmon** est un poisson qui peut être pêché avec le [Fishing Rod](/fishing-rod), et peut être cuisiné en [Salmon](/salmon). Le Raw Salmon ne peut pas être consommé.

## Peut être obtenu de

*   [Fishing](/fishing)
*   [Dorpat Fishing Master](/dorpat-fishing-master)

### Butins

*   [Kobalos](/kobalos) (5%)
*   [Black Rat](/black-rat) (5%)
*   [Grizzly Bear](/grizzly-bear) (2%)
*   [Polar Bear](/polar-bear) (2%)
