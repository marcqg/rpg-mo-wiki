> 🇫🇷 Traduction française — nom original (anglais) : **Weapons** — <a href="/rpg-mo-wiki/weapons">voir la page en anglais</a>

Cette page est un index recensant toutes les armes du jeu, regroupées par catégorie (Keyblades de donateur, Bâtons, Baguettes, Dagues, Épées à une main, Épées à deux mains, Haches, Marteaux, Masses, Divers). Chaque tableau liste le nom, les prérequis, le prix et les statistiques (Power, Aim, Armor, Magic, Speed) de chaque arme. Un extrait représentatif de chaque catégorie est traduit ci-dessous ; la liste complète et exhaustive reste disponible sur la <a href="/rpg-mo-wiki/weapons">version anglaise</a> de cette page.
