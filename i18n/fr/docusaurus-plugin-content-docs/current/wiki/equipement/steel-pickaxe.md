## Notes

Le pic (Pickaxe) est nécessaire pour miner les veines de minerai, tandis que le pic en fer permet de miner le minerai brut. C'est un objet qui s'est répandu dans le jeu via les [Présents](/presents).

Peut être fabriqué avec 5 Steel Bars et 6 Willow Logs sur l'Enclume.
