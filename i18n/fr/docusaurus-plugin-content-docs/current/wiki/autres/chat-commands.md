> 🇫🇷 Traduction française — nom original (anglais) : **Chat Commands** — <a href="/rpg-mo-wiki/chat-commands">voir la page en anglais</a>

Activer le mod Chat Extensions ajoute le filtre de chat ainsi que de nombreuses autres commandes utiles.

_Les commandes suivantes sont disponibles via /help en jeu._

| Commande | Explication |
| --- | --- |
| /afk | Utilise /afk ou /afk (message) pour définir une réponse automatique aux personnes qui te chuchotent si tu es absent du clavier. Tant que ton statut est « AFK », si tu tapes /afk à nouveau, les réponses automatiques seront désactivées. Sauf si tu es complètement inactif ou si tu joues sur mobile, tu peux toujours recevoir des captchas. |
| /combats | Utilise /combats pour voir le [Niveau de Combat](/combat-level) de tout le monde sur ton monde. Utilise ceci pour voir ton propre [Niveau de Combat](/combat-level) si tu n'as PAS chargé /mods. |
| /cathedral | Utilise /cathedral pour voir combien de temps il reste avant de pouvoir démarrer un autre run de [cathedral](/cathedral). Utilise /cooldowns pour la cathédrale et les tours dans une seule liste. |
| /cl | Utilise /cl avec /mods activé pour voir ton [Niveau de Combat](/combat-level). |
| /cooldowns | Utilise /cooldowns pour une liste du temps restant avant de pouvoir démarrer toutes les Tours et la Cathédrale en une seule commande. |
| /counter | Utilise /counter pour voir le nombre d'actions associées à une compétence effectuées, les dégâts infligés, le nombre de kills, etc. Ceci n'est suivi que pour l'appareil actuel, et peut être réinitialisé avec /counter clear. |
| /daily | Utilise /daily pour voir le nombre de jours consécutifs que tu as sur ton compteur de [récompenses quotidiennes](/daily-rewards). |
| /find | Utilise /find (monstre) ou (matériau) ou (nom de ville/terre) pour obtenir le nom de la carte ou les coordonnées de ce que tu cherches. |
| /fire | Utilise /fire pour voir combien de temps il reste avant de pouvoir démarrer un autre run de [Fire Tower](/fire-tower). Utilise /cooldowns pour la cathédrale et les tours dans une seule liste. |
| /friend | Utilise /friend (joueur) pour rapidement ajouter ou retirer un joueur de/à ta liste d'amis. Exemple : /friend dendrek |
| /help | Utilise /help pour voir la liste des commandes de chat du mod. Pour lire la description d'une commande, tape /help &#123;commande}.<br/>Liste des commandes : afk, combats, [cathedral](/cathedral), daily, find, friend, help, id, ignore, join, leave, maintenance, m00, mods, obj, online, o, penalty, ping, played, r, savemap, saveplayer, world, timer, totalexp, totalvalue, xp, wiki. |
| /ice | Utilise /ice pour voir combien de temps il reste avant de pouvoir démarrer un autre run de [Ice Tower](/ice-tower). Utilise /cooldowns pour la cathédrale et les tours dans une seule liste. |
| /id | (Pour le débogage) Utilise /id (objet) (params=) (valeur) pour rechercher des informations dans la base de données du jeu. Cette commande est principalement destinée au débogage et ne sera pas utile à la plupart des joueurs. |
| /ignore | Utilise /ignore (joueur) pour rapidement ajouter ou retirer un joueur de/à ta liste d'ignorés. Exemple : /ignore dumbplayer |
| /join | Utilise /join (CH) (où CH est un nom de canal valide, écrit en majuscules, comme EN, DE, 18, etc.) pour rejoindre ce canal. Exemple : /join EN<br/>/join sert aussi à rejoindre tout événement en cours, comme un trivia ou un tournoi d'arène. (Il faut être dans une ville et sur le bon monde pour rejoindre un mini-jeu) |
| /leave | Utilise /leave (CH) (où CH est un nom de canal valide, écrit en majuscules, comme EN, DE, 18, etc.) pour quitter ce canal. Exemple : /leave EN |
| /maintenance | Utilise /maintenance pour voir combien de temps il reste avant le prochain redémarrage de maintenance pour le monde sur lequel tu es. |
| /maintenance all | Utilise /maintenance all pour voir combien de temps il reste avant le prochain redémarrage de maintenance pour tous les mondes à la fois. |
| /market | Utilise /market pour voir tes transactions de marché précédentes (achats et ventes) sur jusqu'à la semaine précédente (utilisateurs classiques) ou 6 mois (premium). |
| /m00 | Utilise /m00 pour changer ton apparence visuelle en celle d'une... vache ! Tu peux prolonger la durée de cette commande avec /m00 # (par exemple /m00 30 pour fixer la durée à 30 secondes). La durée maximale est de 120 secondes. Taper /m00 sans nombre réinitialise le minuteur à 1 seconde. |
| /mods | Utilise /mods pour ouvrir le menu Activer les [Mods](/mods). |
| /nature | Utilise /nature pour voir combien de temps il reste avant de pouvoir démarrer un autre run de [Nature Tower](/nature-tower). Utilise /cooldowns pour la cathédrale et les tours dans une seule liste. |
| /obj | (Pour le débogage) Utilise /obj (objet) (id) (params) pour lister les paramètres de l'objet(id). Cette commande est principalement destinée au débogage et peut ne pas être utile à la plupart des joueurs. |
| /online | Utilise /online pour voir la liste des joueurs actuellement en ligne sur l'ensemble du jeu. |
| /o | Utilise /o (joueur) pour vérifier si ce joueur est en ligne. C'est un moyen rapide de confirmer le statut en ligne d'un joueur sans parcourir la liste /online. Exemple : /o dendrek |
| /penalty | Utilise /penalty pour voir combien de points de captcha tu as en réserve. Tu peux en garder jusqu'à 4 et dois utiliser le 5ème. Il est recommandé d'utiliser les points en réserve quand l'événement 2x expérience est actif. Si tu atteins -5 points, tu iras en prison. |
| /ping | Utilise /ping pour voir l'ampleur du délai (appelé latence) entre ton ordinateur et le serveur. Chaque 1000ms équivaut à 1 seconde de délai. |
| /ping all | Utilise /pingall pour voir l'ampleur du délai (appelé latence) entre ton ordinateur et les serveurs pour tous les mondes. |
| /played | Utilise /played pour voir combien de temps s'est écoulé depuis la création de ton personnage actuel. C'est une mesure du temps depuis ton début, pas du temps de jeu réel. De plus, RPG MO utilise un jour de 20 heures. |
| /r | Utilise /r pour répondre à la dernière personne qui t'a chuchoté. Si un joueur t'a chuchoté assez récemment, /r se changera immédiatement en /w "nomdujoueur". De plus, utilise PageUp et PageDown pour parcourir les précédentes cibles de chuchotement. |
| /savemap | Utilise /savemap pour sauvegarder la carte actuelle dans un fichier .PNG dans ton presse-papiers. Attention, cela peut prendre du temps à générer ! À ne pas utiliser sur mobile.<br/>_/savemap Dorpat_ |
| /savemonster | Utilise /savemonster suivi du nom du monstre pour sauvegarder un PNG du monstre dans ton presse-papiers. À ne pas utiliser sur mobile.<br/>_/savemonster Efreet_ |
| /savenpc | Utilise /savenpc suivi du nom du PNJ pour sauvegarder un PNG du PNJ, ce qui inclut les mobs. |
| /saveplayer | Utilise /saveplayer suivi du nom du joueur pour sauvegarder un PNG du joueur dans ton presse-papiers.<br/>_/saveplayer Bbrian_ |
| /saveitem | Utilise /saveitem "nom de l'objet" pour sauvegarder un fichier .png d'un objet du jeu. Utile pour les images d'objets à télécharger sur le Wikia en ligne. |
| /saveobj | Utilise /saveobj pour des éléments comme le coffre de ville, la taverne ou le fer/minerai de fer/veine de fer. Graphismes en jeu qui ne sont pas d'autres types d'objets /save. |
| /savepet | Utilise /savepet "nom du familier" pour sauvegarder un fichier .png d'un familier. |
| /saveachievement | Utilise /saveachievement "nom du succès" pour sauvegarder un fichier .png d'un succès. |
| /tax | Utilise /tax pour voir ton pourcentage de taxe actuel. Utilise /tax \[prix\] pour voir tes prix calculés. Les joueurs premium reçoivent une réduction sur leur taux de taxe de marché de 0,1% par mois de premium continu, jusqu'à descendre de 4% à 3%. |
| [/timer](/timer) | Utilise /timer pour vérifier les minuteurs déjà créés. Tu peux aussi créer un compte à rebours (avec /timer set), une horloge (avec /timer start), supprimer des minuteurs (avec /timer clear), et même donner des noms aux minuteurs (avec /timer (nom) (commande)). Tape /help timer (set/start/clear/name) pour plus de détails. |
| /tip | Utilise /tip pour recevoir une [astuce de jeu](/game-tips) aléatoire. |
| /totalexp | La commande /totalexp affiche ton expérience totale accumulée dans toutes les compétences.<br/>Avec /totalexp \[#\] tu peux voir l'expérience totale nécessaire pour atteindre un certain niveau.<br/>/totalexp \[#\] \[#\] te montrera l'expérience totale nécessaire pour passer d'un certain niveau à un autre (par exemple /totalexp 10 16 te montrera combien d'expérience est nécessaire pour passer du niveau 10 au niveau 16 dans n'importe quelle compétence). L'expérience nécessaire pour tous les niveaux de compétence est la même. |
| /xp | Utilise /xp pour voir si un événement 2x expérience est actuellement en cours et voir sa durée le cas échéant. |
| /wiki | Utilise /wiki pour ouvrir le wiki en jeu. Tu peux aussi effectuer une recherche avec cette commande.<br/>/wiki (option1) (option2) (option3) etc., où chaque option « remplit » l'une des cases de recherche du wiki.<br/>Pour plus de détails, tape /help wiki options. Le wiki possède des menus déroulants qui doivent être remplis.<br/>Pour effectuer une recherche wiki avec la commande /wiki, tu dois « remplir » chaque case avec une valeur appropriée. Les différentes parties de la recherche doivent être incluses pour que cela fonctionne.<br/>Voir aussi : le [Guide des Commandes de Chat du Wiki](/wiki-chat-commands-guide) pour un guide approfondi des commandes du wiki. |
| /world | Utilise /world pour voir sur quel monde tu es actuellement.<br/>Utilise /world 1 pour te connecter au monde 1.<br/>Utilise /world 6 pour te connecter au monde 6.<br/>etc. |
