> 🇫🇷 Traduction française — nom original (anglais) : **Abelsonite Ring** — <a href="/rpg-mo-wiki/abelsonite-ring">voir la page en anglais</a>

L'Abelsonite Ring est une bague de fin de jeu qui peut être fabriquée à partir d'[Abelsonite Bars](/abelsonite-bars) et d'un [Ring Mould](/jewelry). Elle peut être utilisée pour fabriquer diverses bagues.
