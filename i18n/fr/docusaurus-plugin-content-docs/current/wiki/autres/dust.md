Dust [![Dust](https://static.wikia.nocookie.net/rpg-mo/images/1/19/Dust.png/revision/latest?cb=20230210232724)](https://static.wikia.nocookie.net/rpg-mo/images/1/19/Dust.png/revision/latest?cb=20230210232724) est utilisée dans l'[Élevage](/breeding) pour nourrir les familiers (pets). Elle peut être fabriquée grâce à l'[Alchimie](/alchemy).
