> 🇫🇷 Traduction française — nom original (anglais) : **Invisible Set** — <a href="/rpg-mo-wiki/invisible-set">voir la page en anglais</a>

L'Invisible Set est un nouvel objet du [MOS Market](/mos-market) à utiliser sur ton mannequin d'armure, permettant de cacher l'équipement que tu portes réellement. Place les objets sur le mannequin puis utilise « Copy Look ». Coût : 450 MOS. Inclut :
