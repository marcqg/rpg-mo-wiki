## De base

Les matériaux sont utilisés pour les [compétences d'artisanat](/skills).

## Types

Il existe différents types de matériaux.

| Type de matériau | Compétence associée |
| --- | --- |
| [Ores](/ores) | [Forge](/forging) |
| [Bars](https://rpg-mo.fandom.com/wiki/Bars)/[Moulds](https://rpg-mo.fandom.com/wiki/Bars) | [Menuiserie](/carpentry), [Forge](/forging), [Bijouterie](/jewelry) |
| Gemmes brutes | [Bijouterie](/jewelry) |
| Gemmes | [Bijouterie](/jewelry), [Forge](/forging), [Fléchisserie](/fletching) |
| Graines | [Agriculture](/farming) |
| Poisson cru | [Cuisine](/cooking) |
