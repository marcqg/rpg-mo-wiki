> 🇫🇷 Traduction française — nom original (anglais) : **Keybinding** — <a href="/rpg-mo-wiki/keybinding">voir la page en anglais</a>

Le Keybinding te permet d'assigner des touches du clavier à des actions en jeu. Clique sur X pour effacer une entrée. NOTE : le déplacement utilise à la fois les touches Flèche Haut et W pour aller vers le NORD (en diagonale vers le haut à droite). Chaque raccourci (Keybind) peut avoir deux touches pour activer cette action, mais les touches deviennent alors exclusives à cette action.

[![Keybinding Window](https://static.wikia.nocookie.net/rpg-mo/images/7/76/Keybinding_Window.png/revision/latest/scale-to-width-down/286?cb=20190301195507)](https://static.wikia.nocookie.net/rpg-mo/images/7/76/Keybinding_Window.png/revision/latest?cb=20190301195507)

## Déplacement

Préconfiguré avec les flèches et les touches de déplacement WASD standard.  
Haut - Nord, Bas - Sud, Gauche - Ouest et Droite - Est

## Inventaire

*   Ouvre ou ferme l'inventaire
*   Charge le pet depuis l'Inventaire
*   Décharge le pet vers l'Inventaire
*   Détruit les objets récoltés - Powermining
*   Déséquipe les objets de l'Inventaire - Les objets équipés et \*Favoris restent dans l'Inventaire quand tu déposes dans le Chest

## Chest

*   Dépôt limité à l'Inventaire personnel
*   Dépôt limité à l'inventaire du pet
*   Dépose le pet et son sac
*   Retire l'objet sélectionné du Chest vers l'Inventaire
    
    [![2019-11-05 22-15-47](https://static.wikia.nocookie.net/rpg-mo/images/c/cd/2019-11-05_22-15-47.jpg/revision/latest/scale-to-width-down/287?cb=20191105141600)](https://static.wikia.nocookie.net/rpg-mo/images/c/cd/2019-11-05_22-15-47.jpg/revision/latest?cb=20191105141600)
    
*   Un préréglage disponible pour tous. Trois de plus pour les comptes [Premium](/premium-account-30-days). NOTE : les préréglages 1-4 ont été réassignés
*   Recherche dans le Chest ou clique sur Recherche en haut du Chest

## Boutique

*   Acheter un
*   Acheter X
*   Acheter le max
*   Vendre un
*   Tout vendre

## Autre

*   Lancer des sorts de Magie pour les pouches avec 1 à 5 emplacements - Préconfiguré avec les touches numériques 1-5
*   Lancer tous les sorts manuellement - [Autocast](/mods) préférable.
*   Fuir le combat - arrête le combat sans se déplacer
*   Mange de la nourriture si blessé, en commençant par le premier aliment de l'Inventaire.

## \*Favoris

Ctrl + clic sur un objet dans ton Inventaire pour le marquer comme 'Favori' dans ton Inventaire. L'objet ne sera pas déposé dans le Chest ni donné au Pet via les commandes de raccourcis. Ctrl + clic sur un objet dans ton Chest pour le marquer comme 'Favori' dans ton Chest. Permet aux options de Tri de s'appliquer, comme le Surlignage, la Mise en évidence et le déplacement des objets vers la première page.
