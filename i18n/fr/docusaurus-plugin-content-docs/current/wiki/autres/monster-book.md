> 🇫🇷 Traduction française — nom original (anglais) : **Monster Book** — <a href="/rpg-mo-wiki/monster-book">voir la page en anglais</a>

Cette page concerne la fonctionnalité Monster Book. Pour des informations sur l'objet Monster Book, voir [Monster Book (Tool)](https://rpg-mo.fandom.com/wiki/Monster_Book_(Tool)).

Le Monster Book est un moyen, en jeu, de suivre le nombre total de kills réalisés pour chaque type de mob, ainsi que de débloquer de nouveaux objets dans la table de butin de chaque mob. Il peut être acheté avec des MOS ou obtenu en drop du (BOSS) Soul Collector ; une fois utilisé, il peut être ouvert via l'onglet Quests en bas de l'écran.
