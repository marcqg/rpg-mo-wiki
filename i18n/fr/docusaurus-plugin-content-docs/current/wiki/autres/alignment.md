> 🇫🇷 Traduction française — nom original (anglais) : **Alignment** — <a href="/rpg-mo-wiki/alignment">voir la page en anglais</a>

Les créatures peuvent avoir deux types d'alignement : Passif (Passive) et Agressif (Aggressive). L'alignement d'une créature peut être trouvé dans l'infobulle en haut de l'écran lorsque le curseur est placé sur elle. Les créatures agressives attaqueront toujours les joueurs qui entrent dans l'une de leurs quatre cases adjacentes, sauf si ceux-ci ont un niveau de combat supérieur de 21 niveaux au leur. Les créatures passives ne ripostent que si elles sont attaquées en premier.

Les créatures dans les [Party Dungeons](https://rpg-mo.fandom.com/wiki/Party_Dungeons) sont toujours agressives, quelle que soit leur infobulle.
