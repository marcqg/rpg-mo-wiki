## Notes

Les Monstres de Fêtes (Holiday Monsters) remplacent les monstres normaux dans tout le jeu ; ils n'ont pas d'emplacement de spawn qui leur soit propre.

Les Monstres de Fêtes n'apparaissent pas dans les [Party Dungeons](https://rpg-mo.fandom.com/wiki/Party_Dungeons).
