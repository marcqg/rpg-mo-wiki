"Explore Explorers" est la 13ème quête proposée dans RPG MO. Le joueur doit tuer 35 [Explorers](/explorer) pour terminer la quête, et recevra 1 des 3 récompenses possibles, tirée au hasard.

| Récompenses |
| --- |
| 2 [MOS](/mos) |
| 266 Exp |
| 874 [Coins](https://rpg-mo.fandom.com/wiki/Coin) |
