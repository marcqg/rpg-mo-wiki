> 🇫🇷 Traduction française — nom original (anglais) : **Objects** — <a href="/rpg-mo-wiki/objects">voir la page en anglais</a>

Les Objects sont tous les objets listés dans le menu de construction (Build Menu) de ton [Island](/island-deed) sous la rubrique 'Objects'. Cela inclut le mobilier pour ton île, les Trophies, les Tombstones, les faux arbres à but décoratif et le mobilier de la Cathedral comme le [Piano](/piano), la Grandfather Clock, etc. Tous les objets fabriqués sont réalisés avec des matériaux conservés dans ton [Chest](/chest) jusqu'à ce qu'ils soient placés sur ton [Island](/island-deed).

Quand tu 'Fabriques' (Make) des objets, beaucoup peuvent être tournés avant que tu ne les 'Places' pour changer la direction qu'ils affichent : les chaises ont quatre orientations possibles, les meubles/lits/tables etc en ont deux, OU après les avoir placés tu peux les tourner sur place avec un clic droit sur l'objet. Très utile pour orienter les clôtures, ou pour ne pas avoir à vider un meuble pour le retourner.

Les objets fabriqués sont listés ici. Pour les objets non fabriqués, utilise le menu Build - Objects pour voir 'All formulas' sur ton île.

Voir aussi [Walls](/walls) et [Floors](/floors).

## Trophées (Trophies)

Les Trophies témoignent de tes exploits contre les Boss et sont chacun fabriqués à partir de 20 têtes. Le Trophy of Game Master s'achète pour 500 MOS ou peut-être sur le Market des joueurs. Voir le menu Island Build.

## Arbres (Trees)

Les arbres pour ton île sont UNIQUEMENT DÉCORATIFS et ne peuvent pas être coupés pour du bois. Chacun peut être tourné (Rotated) avant ou après le 'Place' pour montrer sa croissance, de la souche à l'arbre adulte. Voir le menu Island Build.
