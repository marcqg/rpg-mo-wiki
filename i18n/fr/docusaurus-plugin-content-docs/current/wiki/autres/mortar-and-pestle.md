> 🇫🇷 Traduction française — nom original (anglais) : **Mortar And Pestle** — <a href="/rpg-mo-wiki/mortar-and-pestle">voir la page en anglais</a>

Le **Mortar And Pestle** est un outil utilisé en [Alchemy](/alchemy) pour fabriquer divers types de poudres (dust). Il est également utilisé en [Fungiculture](/fungiculture) pour fabriquer divers types de spores.
