> 🇫🇷 Traduction française — nom original (anglais) : **Hexer Outfit** — <a href="/rpg-mo-wiki/hexer-outfit">voir la page en anglais</a>

Disponible uniquement pendant une durée limitée, le Hexer Outfit est un ensemble d'équipement utilisé uniquement comme costume. +1 armure sur toutes les pièces sauf les gants. Coût : 600 MOS. S'utilise sur un mannequin d'armure comme n'importe quel costume.
