> 🇫🇷 Traduction française — nom original (anglais) : **Combat Level** — <a href="/rpg-mo-wiki/combat-level">voir la page en anglais</a>

Le Combat Level, aussi connu comme le niveau du joueur, ou CL cl.

Pour voir votre CL, tapez la commande dans le chat /combats et cherchez votre nom et niveau parmi les autres joueurs du monde sur lequel vous êtes, ou si vous avez [/mods](/mods) activé, tapez la commande /cl dans le chat ou survolez votre personnage pour afficher les infos en pop-up.

Le Combat Level est utilisé pour :

*   Créer et rejoindre des [Party Quest Dungeons (PQs)](https://rpg-mo.fandom.com/wiki/Party_Dungeons).
*   Pour le [PvP en NML](https://rpg-mo.fandom.com/wiki/No_Man%27s_Land_(PVP)) afin de déterminer qui peut vous attaquer.

*   **Les monstres agressifs n'initieront pas d'attaque s'ils ont 20 niveaux ou plus de moins que le Combat Level du joueur (sauf dans les [Party Quest Dungeons](https://rpg-mo.fandom.com/wiki/Party_Dungeons) et en [NML](https://rpg-mo.fandom.com/wiki/No_Man%27s_Land)).**

C'est un assez mauvais moyen de déterminer le potentiel de combat de quelqu'un ; le Combat Level est représenté par le total des statistiques de base, car les personnages spécialisés dans une ou deux statistiques de combat ont tendance à être plus puissants que ceux avec des niveaux équilibrés dans les six compétences. Cela s'explique par le fait que les valeurs de statistiques d'[équipement](/equipment) augmentent de façon exponentielle avec le niveau requis pour les porter, donc un meilleur [équipement](/equipment) peut être porté à des niveaux plus bas.

Si **(Acc+Str+Def+Health+Arch)** / 4 > Magie, alors le diviseur Magie = 6, sinon diviseur = 4

Si **(Acc+Str+Def+Health+Magic)** / 4 > Archerie, alors le diviseur Archerie = 6, sinon diviseur = 4

Combat Level = **(Acc+Str+Def+Health)** / 4 + (Magie / diviseur Magie) + (Arch / diviseur archerie)

Une meilleure façon de déterminer sa capacité de combat globale est :

*   comparer le total des statistiques ajustées _(en haut à droite)_ avec celles d'un mob.

Cela peut se faire en survolant avec la souris, ou sur écran tactile en touchant la case où se trouve le mob via un menu (comme l'inventaire).

## Niveau de compétence

Les compétences n'ont pas de niveau maximum, cependant le plafond observé en pratique est le niveau 150 car il faut très longtemps pour l'atteindre et les compétences n'ont actuellement pas de contenu prévu au-delà de 150.

Les effets temporaires qui augmentent ou diminuent les niveaux de compétence sont annulés à raison d'1 point par minute. Les potions qui augmentent les niveaux de compétence et les dégâts à la santé en sont les principaux exemples.
