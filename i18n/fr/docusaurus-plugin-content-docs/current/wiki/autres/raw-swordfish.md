REDIRECT Template:Raw FishLe Raw Swordfish est un poisson que l'on peut attraper en pêchant avec le [Wooden Harpoon](/wooden-harpoon) ou le [Multi-tool](/multi-tool), et qui peut être cuisiné en [Swordfish](/swordfish). Le Raw Swordfish ne peut pas être consommé cru. Le Raw Swordfish nécessite le niveau 50 de Cooking pour être utilisé.

## Peut être obtenu par

*   [Fishing](/fishing)
*   [Skeletal Dragon](/skeletal-dragon)
*   [Narwa](/narwa) ([Fishing](/fishing) niveau 50-55) via [Wooden Harpoon](/wooden-harpoon)
