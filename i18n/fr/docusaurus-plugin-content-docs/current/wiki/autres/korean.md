## _Bienvenue sur le wiki RPG MO !_ **Qu'est-ce que RPG MO ?**

[RPG MO](http://www.rpg.mo.ee/) est un jeu de type bac à sable (sandbox), en 2D, avec 18 compétences à entraîner, et de nouveaux contenus arrivent régulièrement via les mises à jour.

Ce jeu prend en charge le HTML 5 et propose divers modes d'hébergement dans le navigateur via [Kongregate](http://www.kongregate.com/), [MocoSpace](http://www.mocospace.com/games;sid=aaaWV_iwqCgbSfxZxJmzv?gid=1321&r=252&#confirm) et [Steam](http://store.steampowered.com/app/372800/). Il est également disponible sur le [Google Play Store](https://play.google.com/store/apps/details?id=ee.mo.rpgnew), et tu peux aussi télécharger un client pour [Windows, Mac, Linux et Android](http://mo.ee/download.html). Le site Modb se trouve [ici](http://rpgmo.out-line.co/#/).

## Configuration minimale du jeu

*   Connexion Internet requise
*   Navigateur web : dernière version à jour de Chrome/Firefox/Internet Explorer/Opera
*   CPU : 1 GHz+ (recommandé)
*   RAM : au moins 256 Mo (512 Mo recommandé)
*   Disque dur : 50 Mo d'espace libre (pour les fichiers de cache)
*   Entrées : souris, clavier, écran tactile, manette de jeu
