[![Menu](https://static.wikia.nocookie.net/rpg-mo/images/9/99/Menu.png/revision/latest?cb=20190301194153)](https://static.wikia.nocookie.net/rpg-mo/images/9/99/Menu.png/revision/latest?cb=20190301194153)

Le menu s'ouvre en survolant l'icône la plus à gauche en haut à droite de l'écran.

*   Game options - Régler les paramètres du jeu
*   [Keybindings](/keybinding) - Définir les raccourcis clavier pour les actions
*   Spectate mode - Regarder un autre joueur
*   [Fighting mode](/fighting-mode) (réglage actuel)
*   [MOS Market](/mos-market) - Marché de la monnaie du jeu
*   Refer a Friend
*   Visit homepage - Ouvre un nouvel onglet dans le navigateur
*   Highscores - Ouvre un nouvel onglet dans le navigateur
*   Game forum - Ouvre un nouvel onglet dans le navigateur
*   Player info - Fenêtre d'informations sur ton compte
*   [Wiki](/wiki-chat-commands-guide) & [Mods](/mods) menu
*   Logout - Quitter le jeu avant de fermer la fenêtre
