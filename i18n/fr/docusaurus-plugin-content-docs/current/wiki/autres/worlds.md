> 🇫🇷 Traduction française — nom original (anglais) : **Worlds** — <a href="/rpg-mo-wiki/worlds">voir la page en anglais</a>

Il existe six (6) mondes parmi lesquels le joueur peut choisir en lançant le jeu. Chaque monde offre la même chose que les autres, bien que le monde 3 soit réservé aux membres premium. Le choix du monde n'affecte pas le jeu de façon majeure, mais il existe de petites différences.

## Mondes standards

Les mondes 1, 2, 4, 5 et 6 sont tous des mondes pour les comptes joueurs standards, et bien que ces mondes n'offrent aucun avantage entre eux, certains mondes peuvent être choisis pour différentes raisons. Par exemple, le World 2 est souvent choisi pour les groupes de donjon car c'est généralement le monde le plus peuplé. D'autres mondes comme les 4 et 5 sont souvent choisis pour leur population _plus faible_, où davantage de monstres peuvent être disponibles et où le ping peut être plus bas.

## Monde premium

Actuellement, le World 3 est le seul monde disponible pour les utilisateurs premium, offrant aux utilisateurs un ping plus faible grâce à une population très réduite. Les boss y sont également bien plus souvent disponibles pour cette même raison.
