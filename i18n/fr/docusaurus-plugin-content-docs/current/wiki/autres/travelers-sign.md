[![Travelers Sign](https://static.wikia.nocookie.net/rpg-mo/images/4/47/Travelers_Sign.png/revision/latest?cb=20160606080602)](https://static.wikia.nocookie.net/rpg-mo/images/4/47/Travelers_Sign.png/revision/latest?cb=20160606080602)

Les Traveler Signs peuvent être situés à divers endroits sur chaque carte et servent à se téléporter vers une autre carte connectée dans le monde de RPG MO. Les connexions peuvent être visualisées via la World Map en sélectionnant d'abord la Mini-Map située dans le coin supérieur gauche de l'écran de jeu. L'activation des [Mods](/mods) les plus récents fournira davantage d'informations.

Avec le mod Enhanced Map chargé, le Travelers Sign est indiqué par un cercle bleu clair sur la mini-carte. Survoler chaque cercle affiche les informations de destination pour ce Travelers Sign.
