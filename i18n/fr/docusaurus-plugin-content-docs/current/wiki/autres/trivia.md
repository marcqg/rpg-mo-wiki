> 🇫🇷 Traduction française — nom original (anglais) : **Trivia** — <a href="/rpg-mo-wiki/trivia">voir la page en anglais</a>

Trivia -> Les Modérateurs/Administrateurs fournissent des questions aux joueurs. Chaque bonne réponse rapporte des points.

[![Ss+(2016-01-07+at+11.46.41)](https://static.wikia.nocookie.net/rpg-mo/images/0/07/Ss%2B%282016-01-07%2Bat%2B11.46.41%29.png/revision/latest?cb=20170228113043)](https://static.wikia.nocookie.net/rpg-mo/images/0/07/Ss%2B%282016-01-07%2Bat%2B11.46.41%29.png/revision/latest?cb=20170228113043)

Une fois le trivia créé, il sera annoncé dans le chat mondial.

[![Ss+(2016-01-07+at+11.39.30)](https://static.wikia.nocookie.net/rpg-mo/images/0/0a/Ss%2B%282016-01-07%2Bat%2B11.39.30%29.png/revision/latest?cb=20170228113329)](https://static.wikia.nocookie.net/rpg-mo/images/0/0a/Ss%2B%282016-01-07%2Bat%2B11.39.30%29.png/revision/latest?cb=20170228113329)

Après avoir rejoint, vous devez vous **inscrire** à la table du Trivia.

Cliquez sur la table, **ne la fermez pas !**

[![Ss+(2016-01-07+at+11.41.22)](https://static.wikia.nocookie.net/rpg-mo/images/0/0c/Ss%2B%282016-01-07%2Bat%2B11.41.22%29.png/revision/latest?cb=20170228113645)](https://static.wikia.nocookie.net/rpg-mo/images/0/0c/Ss%2B%282016-01-07%2Bat%2B11.41.22%29.png/revision/latest?cb=20170228113645)

Une fois toutes les questions terminées (aléatoires à chaque fois), les 3 meilleurs joueurs recevront des récompenses.
