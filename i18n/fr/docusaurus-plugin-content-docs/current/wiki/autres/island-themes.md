> 🇫🇷 Traduction française — nom original (anglais) : **Island Themes** — <a href="/rpg-mo-wiki/island-themes">voir la page en anglais</a>

En sélectionnant « Island » dans le menu Build de ton île, tu peux accéder aux Island Themes pour changer l'apparence de ton paysage. Chacun coûte 1 million de pièces ou 100 MOS et peut être changé quand tu le souhaites. Le [Ship](/ship-building), les meubles, la ferme et les armoires ne sont inclus dans aucun thème.

Il existe aussi des thèmes pour le donjon personnel du joueur : [Dungeon Themes](/dungeon-themes)
