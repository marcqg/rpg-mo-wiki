[![Void Tree](https://static.wikia.nocookie.net/rpg-mo/images/7/79/Void_Tree.png/revision/latest?cb=20170622214121)](https://static.wikia.nocookie.net/rpg-mo/images/7/79/Void_Tree.png/revision/latest?cb=20170622214121) The Void Tree can be cut at level 85 [Woodcutting](/woodcutting) using a [Steel Woodcutter's Axe](https://rpg-mo.fandom.com/wiki/Steel_Woodcutter%27s_Axe) or [Multi-tool](/multi-tool). When cut successfully, a [Void Log](/void-log) is acquired. The log can be used in skills such as [Carpentry](/carpentry) and [Fletching](/fletching).
