Collection Book

The collection book was added during the 2021 Halloween event and can be purchased on the [MOS Market](/mos-market) for 3000 [MOS](/mos).

It is an item that can be placed on the [Player Island](/player-island) that allows players to store event items in the book, going all the way back to the first event in RPGMO (Halloween 2012.)

By default, the book lets you store 1 of each item from the event. You can purchase Collection Book Page from the MOS market for 300 MOS. Each page you add to the book lets you store 5 more of each item in the book.

### **The Collection Book Dropdown**

Below is a snip of what the dropdown shows in the Collection Book. It lists each event in order. Any events not listed means there were not special Event Items to be collected for that Event/Year (for example, Christmas 2014 had no event items.) The 2 numbers after the Event Name & Year indicate how many items have been collected by the user for that event out of the total number available. So in the screenshot below you can see I have collected 1 of 1 of the items in Christmas 2012, but am only at 1 of 5 for Valentine's 2014. This is strictly a count of how many slots have been filed, and not a count of the number of items in the slots. So for example, on Christmas 2012 I have actually stored 6 Santa Hats, but the number in the dropdown is still just 1/1. (You can see this in the Christmas 2012 screenshot below in the "Christmas Collection Book Pages" section.
