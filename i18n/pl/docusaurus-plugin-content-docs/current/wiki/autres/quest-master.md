The Quest Master NPC provides [Skill Quests](/skill-quests).

They can be found at: [Dorpat](/dorpat), [Reval](/reval), [Walco](/walco), [Rakblood](/rakblood), [Cesis](/cesis), [Narwa](/narwa), [Fellin Island](/fellin-island), [Broceliande Forest](/broceliande-forest), [Hell](/hell) and Witches I.

Note that all Quest Masters share the same set of skill quests and cooldowns, regardless of location.
