Template:Infobox Item NewThe Firelord Keyblade can be acquired by buying it for 100 MOS from [MOS Market](/mos-market) or through the [Chest Market](/market-guide) from other players. It is also part of the [Firelord set + Steel Harpoon](https://rpg-mo.fandom.com/wiki/Firelord_set_%2B_Steel_Harpoon) for 500 MOS or the Firelord set + 400k coins for 600 MOS. It requires Accuracy to equip and can be enchanted many times using [Weapon Enchant Scrolls](/enchanting) to get more Aim and Power however this also increases the Accuracy needed to equip it. Be sure you can wield the next level Keyblade before you enchant the one you have. [Enchanting](/enchanting) is done at the [Anvil](/anvil).
