Void I is a map that can be reached from [Blood River](/blood-river) or [Clouds](/clouds). It leads to the three [Towers](/tower). It has an outpost but no town. The safest route comes from [Blood River](/blood-river).

### Path from Clouds to Void I Chest

#### Requirements

*   [Island Deed](/island-deed) in inventory, as this can be used to avoid several [Ancient Wyverns](/ancient-wyvern).
*   Able to survive multiple attacks from an [Undead Dragon](/undead-dragon). (No need to defeat the mob; it can be passed after fleeing combat.)

#### Path

The path can be found at [:File:Void\_I\_Path-Clouds.png](https://rpg-mo.fandom.com/wiki/File:Void_I_Path-Clouds.png).

*   Green tiles are the path to follow.
*   Red tiles are aggressive mob combat tiles.
*   Black tiles are blocked by objects.
