This Page is about the Monster Book Feature. For information on the Monster Book Item, see [Monster Book (Tool)](https://rpg-mo.fandom.com/wiki/Monster_Book_(Tool)).

The monster book is an in-game way to track your total amount of kills for each type of mob, as well as unlock new items into each mobs drop table. It can be either purchased with MOS or dropped by (BOSS) Soul Collector; once used, it can be opened through the Quests tab at the bottom of the screen

[![Quests Page](https://static.wikia.nocookie.net/rpg-mo/images/3/39/Quests_Page.png/revision/latest/scale-to-width-down/360?cb=20240331181909)](https://static.wikia.nocookie.net/rpg-mo/images/3/39/Quests_Page.png/revision/latest?cb=20240331181909)
