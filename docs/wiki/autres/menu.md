Menu is opened by hovering over leftmost icon in top right part of the screen.

*   Game options - Adjust game settings
*   [Keybindings](/keybinding) - Set keyboard commands for actions
*   Spectate mode - Watch other player
*   [Fighting mode](/fighting-mode) (current setting)
*   [MOS Market](/mos-market) - In-game currency market
*   Refer a Friend
*   Visit homepage - Opens new tab in Browser
*   Highscores - Opens new tab in Browser
*   Game forum - Opens new tab in Browser
*   Player info - Info window for your account
*   [Wiki](/wiki-chat-commands-guide) & [Mods](/mods) menu
*   Logout - Exit game before closing window
