**Medusa (Common)** is a common level pet that gives a slight boost to [Archery](/archery). It can be obtained by killing [Nagas](/naga). If a player gains 150,000 [experience](/experience) with it equipped, it will evolve into a Naga (Common). This pet cannot be used in [Breeding](/breeding).
